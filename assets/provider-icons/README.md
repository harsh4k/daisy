# Publisher icons

These are unmodified publisher assets, downloaded through a plain HTTPS fetch.
`sources.json` records the exact source URL, publisher page, retrieval time,
SHA-256 hash and, for Spotify, the official archive member and archive hash.

- Netflix: the Netflix website's Apple touch icon.
- Spotify: `Primary_Logo_Green_RGB.svg` from the developer site's icon download.
- YouTube: the YouTube website's 144 px favicon.
- Chrome: the Chrome product website's 192 px application icon.
- Edge: the Edge welcome site's favicon on Microsoft's Edge CDN.
- Brave: the Brave website's 192 px application icon.

They identify the corresponding media service or browser. Brand assets retain
their respective owners' rights; they are not part of Daisy's own identity.
They are bundled for offline display, with no runtime tracking or icon request.
Unsupported media providers use an existing Font Awesome generic icon.
