# Daisy roadmap (open source)

Measured on 2026-11-14, installed v1.0.7: 142 MB private memory in the main process, 20 threads,
about 1.2% of one core at rest, three processes (launcher, app, crash sink).

## 1. Quality first

| Item | Why | State |
|---|---|---|
| Stop copying system fonts into memory | 48 MB of the 142 MB was five Windows fonts registered twice | done: about 100 MB from source |
| Glitch recorder (`motion_trace.py`) | Real-desktop glitches do not show in offscreen tests | done: right-click, Save glitch report |
| Fix what the reports show | Each report names jumps, freezes, clipping and sideways shifts | waiting for the first reports |
| Folder build with an installer | The one-file exe unpacks 63 MB on every launch and on every hook call | next |
| Replace `requests` with the standard library | About 11 MB and one dependency for two GET calls | next |
| Load Windows media and notification APIs on first use | About 12 MB at start | next |
| Test job on every push | Four releases failed only on the CI runner | next |
| Code signing | SmartScreen warns on every download | owner decision (certificate) |

## 2. Features

1. Agent island: a "working" state with elapsed time, several sessions at once, failed-test and
   error alerts, Codex.
2. Now Playing visuals: live spectrum bars from system audio, album-colour wash, lyrics line.
3. Quick controls: volume and brightness HUD in the pill (replaces the Windows flyout), mute, camera
   and microphone in-use dot.
4. Live activities: downloads, timers, screen recording, battery low, Bluetooth device connected.
5. Calendar: next meeting countdown in the pill and a join button.
6. Clipboard and file shelf: last items, drag out.

## 3. Design

- Themes are now one saturated accent each on true black (Dark Matter, Graphite, Amethyst, Midnight,
  Rose, Mint, Sunset). Next: let a theme also set the page light and the eye glow.
- Eyes: more moods (focused while a timer runs, listening while music plays), and the eyes inside the
  notification chip.
- One motion language: every transition through the same spring, measured by the recorder.
